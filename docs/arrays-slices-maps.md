# Arrays, Slices e Maps

Go oferece diferentes estruturas de dados.

## Array

```go
var numeros [3]int
```

## Slice

```go
nomes := []string{"Ana", "Carlos"}
```

## Map

```go
idades := map[string]int{
    "Ana": 20,
}
```

| Estrutura | Descrição |
|---|---|
| Array | tamanho fixo |
| Slice | tamanho dinâmico |
| Map | chave e valor |

!!! note "Dica"
    Slices são muito mais usados que arrays em Go.
