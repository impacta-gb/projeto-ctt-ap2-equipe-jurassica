# Trabalho AP2 — Documentação da Linguagem Go

Este projeto tem como objetivo apresentar uma documentação introdutória da linguagem Go, utilizando a ferramenta Zensical para geração de páginas.

A documentação aborda conceitos fundamentais da linguagem, incluindo:

- Sintaxe básica
- Variáveis
- Estruturas de controle
- Arrays, slices e maps
- Structs e métodos
- Tratamento de erros
- Goroutines
- Channels
- Gerenciamento de Pacotes (Go Modules)
- Testes Automatizados em Go

Além disso, o projeto aplica práticas de desenvolvimento colaborativo utilizando:

- GitHub
- Branches
- Pull Requests
- Revisão de código
- GitHub Actions
- CI/CD com GitHub Pages
