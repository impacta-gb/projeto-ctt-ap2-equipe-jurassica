# Introdução e Instalação

Go é uma linguagem criada pelo Google com foco em simplicidade, concorrência e performance.

## Instalação

Acesse o site oficial:

https://go.dev/

## Verificando instalação

```bash
go version
```

## Primeiro programa

```go
package main

import "fmt"

func main() {
    fmt.Println("Olá, Go!")
}
```

!!! note "Importante"
    Todo programa Go começa pela função main().
