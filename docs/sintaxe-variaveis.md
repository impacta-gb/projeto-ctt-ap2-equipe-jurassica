# Sintaxe Básica e Variáveis

Go possui tipagem estática e sintaxe simples.

## Declarando variáveis

```go
var nome string = "Kapazo"
var idade int = 20
```

## Declaração curta

```go
cidade := "São Paulo"
```

## Constantes

```go
const pi = 3.14
```

| Tipo | Exemplo |
|---|---|
| int | 10 |
| string | "texto" |
| bool | true |

!!! note "Dica"
    O operador := infere automaticamente o tipo da variável.
